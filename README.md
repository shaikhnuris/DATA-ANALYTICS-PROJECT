Healthcare Analytics & Patient Intelligence Dashboard
About the Project
This is my academic major project built using Microsoft Excel. It includes six workbooks covering different areas of healthcare analytics, such as patient data, diseases, doctors, hospital operations, and revenue.

The aim is to organize healthcare data, explore useful patterns, and present insights through dashboards and visualizations.

Project Workbooks
Healthcare Analytics & Patient Intelligence – Main dashboard
Patient Analytics – Patient-related analysis
Disease Analytics – Disease-related trends
Doctor Analytics – Doctor-related analysis
Hospital Operations Analytics – Hospital operations overview
Post and Revenue Analytics – Post-related and revenue analysis
Tools Used
Microsoft Excel
PivotTables
Charts and Visualizations
Slicers and Filters, where implemented
What I Learned
Through this project, I practised data analysis, dashboard creation, and data visualization in Excel. It also helped me understand how data can be presented to support better decision-making.
